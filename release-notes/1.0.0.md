# FU — EmuFramework v1.0.0

Released 2026-09-03.

## Summary

This framework update establishes EmuFramework 1.0.0 as a metadata-driven platform for building and operating business applications with a generated web interface and server runtime.

## Improvements

- Provides a browser-based Web Designer for Apps, models, forms, lists, line grids, menus, permissions, reports, views, Functions, and Scripts.
- Generates responsive business interfaces backed by SQLite, with validation, lookups, navigation, import/export, and reporting.
- Supports layered metadata customization, role-based security, encrypted fields and integration secrets, REST integrations, and reviewed AI proposals.
- Provides Docker deployment with persistent storage, backup and restore, health diagnostics, and an idempotent upgrade path.

## Fixes

None documented.

## Breaking changes and migration

This is the first release under the three-component FU/PU version model. Legacy four-component tags remain immutable history and are not extended.

## Upgrade notes

Follow the installation or upgrade guide in the [EmuFramework documentation repository](https://github.com/emu479p01/emu-framework-docs). Back up both SQLite databases and preserve `.emu-secret.key` before upgrading an existing installation.

The tagged source includes automated tests, type checking, and production build commands for the core, server, and client packages.
